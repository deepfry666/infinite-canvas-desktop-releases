## 说明

- 四季画布只作为桌面应用发行；`web/` 是 Electron 渲染层目录，不是独立网页产品。
- 当前画布项目和“我的素材”保存在本地桌面工作区，跨设备可自行配置 WebDAV 同步。
- AI API Key 保存在应用本地配置中，并由桌面渲染层直接请求用户配置的兼容接口。
