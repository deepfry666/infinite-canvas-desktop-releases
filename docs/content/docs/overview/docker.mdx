# Docker Deployment (Unsupported)

This page remains from the upstream project's earlier history. FourJ Canvas is distributed only as an Electron desktop installer and does not provide a web application container.

Install the Windows desktop build from the public releases repository, or run `npm run desktop:dev` for source development.
