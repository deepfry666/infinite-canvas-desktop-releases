# Render Deployment (Unsupported)

This page remains from the upstream project's earlier history. FourJ Canvas is now an Electron desktop-only product and is not distributed through Render, Vercel, or another web host.

Install the Windows desktop build from the public releases repository, or run `npm run desktop:dev` for source development.
