# 待测试

公开源码快照不是新安装包版本。Node 24 环境下的原有断言、类型检查和渲染层构建已验证，范围见根目录 `SOURCE_VERIFICATION.md`。本快照不附带 MiSans，未安装时使用既有系统字体回退；下一次发版前仍需在 Windows 验证换行、字体清晰度、打包许可文件、稳定/测试更新与工作区保留。

桌面侧栏版本号和「系统与关于」中的当前版本应显示完整的 v0.1.11-beta.4。

- 中转图片响应：文生图与参考图编辑应能识别 URL 数组、单个图片对象及 `image_url` / `imageUrl` 字段；仍需在 Windows 上使用用户的 CPA 渠道确认显示和本地保存。当前回归使用模拟响应，不能据此确认用户实际接口返回格式或原始故障根因。
- 远程结果兜底：CPA 返回有效远程图片地址、但桌面进程无法下载到工作区时，生图工作台和画布仍应保留远程地址并显示成功，不得把已成功生成的任务显示为失败。

- 创作 Skill 创建与发布：从资产区导航进入「创作 Skill」，确认内置「编辑海报」Recipe 保持只读，个人 Skill 可搜索、筛选、收藏、启用、复制和删除。分别从空白 Recipe、画布上一条连续且无分支的流程、以及一组前后对比图创建草稿。前后对比通用支持 PNG、JPEG 和 WebP，macOS 桌面端额外支持 HEIC/HEIF 并转为规范化 PNG；解码后的方向与尺寸保持正确，只保存规范化的本地测试夹具，可用视觉文字模型提炼风格并在失败后手动补全，结果图不得被当作生产 Recipe 参考。修改 Recipe 后旧试跑结果立即失效；只有与当前定义完全一致的画布试跑可通过门禁并发布为不可变版本，新版本默认禁用。
- 创作 Skill 画布执行与恢复：在内置对话中附加已启用、兼容且健康的已发布 Skill，检查待确认内容中的参数、目标、参考图、执行步骤、输出数和模型调用数后再批准。多步生成/编辑必须按顺序执行，只把最终结果落到预期画布节点旁；拒绝确认或画布状态过期时不改动画布，远程提交结果不明时不得重复提交。在不同阶段离开页面、重启应用或取消，并继续查询待定中转任务，可恢复任务应且仅应继续一次；强制退出发生在输出暂存后、账本登记前，或节点写入内存后、画布持久化完成前时，重启只能补记账或补落盘，不得再次请求 Provider 或创建重复节点。结果不明的提交显示可能计费警告及「继续查询」「结束记录」，结束本地记录不得声称已撤销远程费用。
- 创作 Skill 传输与崩溃安全：将已发布版本导出为 `.fourj-skill`，检查 Recipe 和内置图片摘要，再以「外部、未验证、默认禁用」的个人草稿导入。导入 `SKILL.md` 后，它只作为无法编辑、试跑或发布的隔离记录保留。包含路径穿越、重复或冲突路径、不支持 ZIP 特性、非法清单、损坏图片或未声明能力的包必须被拒绝，不得留下半套草稿、报告、资产或已更改的资料库指针。在 SKILL.md 导入、包导入、发布和同步恢复写入资产、草稿、报告/版本或目录后强制关闭桌面应用；重启后，未提交操作只能删除由它创建、字节仍完全一致且无任何引用的文件，已提交操作、并发编辑的草稿、预先存在的不可变内容、共享资产及任何无法确认的状态都必须保留。
- 创作 Skill 统计、隐私与 WebDAV 同步：「创作统计」只统计已结算的运行，分开展示生产使用与试跑，并按 Skill、版本和来源展示真实模型调用、已落盘结果、耗时与结果；记录不得包含提示词、媒体、文件名、路径、URL、中转任务或画布/对话标识。WebDAV 只同步权威已发布资料库、删除墓碑、不可变资产和隐私安全的已结算运行摘要；草稿、内置偏好、API Key 和活动执行状态保持本地。验证首台设备恢复、基于上次检查点的正常远端单边前进、可跨重启的恢复点创建与幂等重试；本地/远端资料库已分叉、检查点过期、本地 head 已变更、同步包损坏、文件缺失或服务端不可靠支持强 ETag 条件写入时，普通恢复必须保持双方不动。只有从冲突审查入口明确选择「以远端替换本机」时才允许替换，且必须先创建本机恢复点、继续保留本地草稿并使用条件写入拒绝并发变化。
- 画布快捷返回与固定尺寸菜单：顶部应依次提供「主页」「所有画布」、侧栏开关、当前画布标题和「对话」；点击「所有画布」直接返回画布库 `/canvas`，点击「主页」仍返回首页。无论画布放大或缩小，双击空白处或从节点连线末端打开的节点选择菜单都保持稳定、清晰且可点击的屏幕尺寸，不随画布内容一起缩小。
- 素材文件夹与可移植素材包：「我的素材」支持全部、未归档、自定义文件夹的新建、重命名、删除及单个/批量移动；删除文件夹只把其中素材移回未归档，不移动或删除工作区媒体，也不改变画布和生成记录共享的 `storageKey` 引用。画布左栏与素材选择弹窗使用同一套文件夹筛选，在当前文件夹上传时自动归入该文件夹。重启应用、切换工作区并进行 WebDAV 同步后，文件夹与素材删除墓碑应保持稳定，不得复活已删除素材或产生同名文件夹。v2 导出导入应保留文件夹和媒体，v1 包仍可读取；缺失媒体必须阻止导出，损坏素材包不得留下半套元数据或孤立媒体。
- 素材替换与删除清理：替换或删除只被当前素材使用的 `workspace:` 图片、视频或音频后，只有在画布、我的素材、工作台、生成记录和活动临时任务均不再引用时才可移除文件；共享文件、活动生成、引用数据异常、IPC 异常或删除失败时都必须保留文件。
- 对话文字选择：右侧内置对话中的用户消息、AI 回复、AI 理解、完整提示词和已执行操作结果都可以用鼠标拖选并按 `Ctrl/Cmd + C` 复制；选择文字时不得触发画布节点复制，按钮和折叠卡片仍保持正常点击。
- 完整版本通知：桌面侧栏、「系统与关于」、版本更新弹窗、应用内更新完成提示和 Windows 更新完成系统通知都显示完整的 `v0.1.11-beta.4`。
- 本版统一收口验收：画布库、我的素材、提示词、创作统计、回收站和设置页使用相同的无 eyebrow、表情或装饰图标页头；设置六分区的可见章节按 `01/02/03` 自动连续编号，隐藏桌面功能后不得断号。创作统计明确分成「历史创作」与「当前内容」，上方日期只筛选历史，下方仅统计当前画布节点；删除作品、节点、画布、素材、生成记录、清空回收站或清理媒体后，历史累计不得减少。历史应覆盖工作台与画布的图片、视频、音频、文字及内置对话提示词润色，并准确区分成功、部分成功、失败与取消；部分成功后停止仍保留成功数，重试失败也必须入账，成功率只按已完成结果计算并单列取消数。旧工作台日志与独立历史按稳定 ID 合并去重并补齐尺寸等缺失字段，生成开始时即保留项目/节点标题快照，删除画布后排行继续显示标题；旧统计迁移前应留下可校验恢复点，迁移写入后必须再次读取校验；配置导入和 WebDAV 并发同步不得覆盖新活动，清除历史必须输入确认短语，且更旧远端清单、旧日志或导入文件均不得使其复活。离开画布时对话立即收起，主页与其他标准页面不再提供重新打开入口；重新进入原画布后本地会话仍保留。
- 画布首开稳定性：从首页新建画布、从「我的画布」打开空画布或已有内容的画布时，应直接进入编辑界面，不得出现 `Cannot read properties of null (reading 'id')` 或 React Router 错误页；未选中节点时浮动工具栏和提示面板保持隐藏，选中节点后再正常显示。
- 画布内置对话确认：首次打开对话应默认为「手动确认」，输入区可切换「自动确认」并选择已配置的文字模型，模型项同时显示渠道；刷新后保留用户选择。选中图片后输入简短改图要求，待确认卡应默认展开并展示 AI 理解、参考图、目标节点、动作、完整提示词、画幅、输出数量和模型调用次数，批准后才执行；历史卡收紧且不得保存参考图 Data URL。「只润色提示词」只返回文字且不出现画布操作。切到自动确认后同一类明确指令直接执行；画布内容或选区变化时拒绝旧提案，普通平移缩放不影响内容提案，只有提案本身要改变视图时才校验视口。模拟损坏的本地会话后，非法消息、附件、引用和重复 ID 应被清洗，合法历史仍可打开；普通页面隐藏的对话面板不得继续暴露 Dialog 语义。
- 对话输入与路由收起：在 Windows 中文输入法组合输入期间，占位文案必须隐藏且不得与拼音重叠；从画布通过主页按钮、浏览器后退或其他跳转离开时，右侧对话立即收起，回到首页时画布左栏也不得残留。重新进入原画布并打开对话后，本地会话和仍在运行的后台任务继续存在。
- 设置分区与滚动：设置页和设置弹窗都应按「AI 服务、创作偏好、同步与迁移、存储与空间、内容来源、系统与关于」六个入口展示；桌面页头和左侧入口固定，仅右侧内容滚动，窄屏保持顶部 Tabs。配置导入导出与 WebDAV 只在「同步与迁移」，本地目录、占用/健康、未引用媒体、缓存与回收站只在「存储与空间」；旧的 `data` 分区记忆打开到「存储与空间」。导出前明确提示包含 API Key/WebDAV 凭据，WebDAV 明确不是版本备份。
- 回收站引用与安全清理：清空或永久删除回收站记录后，页面持续显示删除记录数、实际删除文件数、因引用保留数和失败数。删除前点击「查看引用」应列出画布、素材、其他生成记录和当前工作台等来源及对应存储标识；有引用的文件不得提供强制删除。设置中的未引用媒体扫描仅允许图片、视频和音频，保护 Electron 渲染层中尚未写入工作区文件的画布/素材/记录引用；引用扫描或工作区健康检查失败时清理按钮禁用或操作失败关闭。确认框应明确说明仅保存项目/记录元数据快照，被清理的媒体文件无法从该快照恢复。
- 创作统计与来源：升级前已有工作台生图记录仍计入申请、图片、模型和尺寸统计；升级后工作台与画布的生成、改图、扩图、超分和三视图同时计入，且一次操作不重复计算。统计页显示文本节点/字符数、活跃天数、连续创作、时段、文本来源和画布产出排行，并标注精细追踪启用时间。新建/粘贴/导入、手写修改、AI 生成或 AI 再编辑后来源分别落到手写、导入、AI 或人机共创；旧文本保持「未知」，导入与未知不进入手写/AI 占比分母。活动日志只保存数量、来源、动作、时间和归属，不得保存提示词或正文。
- 「四季流韵」统一动效：首页指针显影应由较快淡金光心与更慢、更大的朱砂外缘形成轻微黏滞拖影，范围比旧版更散但亮度克制；停止约 1.35 秒后，闲置柔光必须在 `FOURJ` 字纹间真实缓慢游移，不能固定在几组字符上只变明暗。一级导航按首页、画布、生图、视频、资产、提示词、统计、设置的顺序以 10–14px 小幅方向过渡，返回时方向严格反转；不支持 View Transition 时的新页后备动效保持相同方向。所有动画不得模糊文字或在停稳后残留 transform。
- 任务归属与独立计时：启动生图或视频任务后切换到另一条历史记录，再点击运行记录，应恢复该任务自己的实时占位、结果和计时，不得被历史提示词或结果覆盖。已完成记录显示冻结耗时，待确认或运行记录不可勾选删除，反复切换记录时已完成耗时不得继续增长。
- APIMart 长耗时生图：含较多参考图的 2K 任务超过十分钟后不得被误判失败；临时网络异常、408/429 和 5xx 轮询错误应退避重试。达到 30 分钟客户端等待窗口后，记录变为「状态待确认」并保留中转任务 ID；点击「继续查询」只能恢复同一任务，不得重新提交。中转明确返回失败时仍应正常标记失败。
- 参考文件复用：从已配置的图片目录向生图或视频工作台拖入多张图片，再次拖入同一批文件时，源目录不得出现重复副本；同内容文件应继续使用同一个工作区标识，参考列表也不得追加重复项。移除参考项、生成记录或清理应用未使用媒体时不得删除被复用的源文件；旧路径、历史结果和自定义分类目录必须继续可读。
- 朱砂视觉与设置层级：浅色主题生成记录悬停使用克制的低透明度朱砂柔光，文字保持墨色；勾选记录只使用轻微朱砂选择环，当前查看记录使用静止暖金锚点。首页 `FOURJ` 在完整首屏内缓慢呼吸且无霓虹扫光，画布卡片沿用同一克制点缀。同步与迁移、存储与空间的章节标题应为 19–20px，并明显大于 14px 说明文字；左侧系统区是唯一常规设置入口，个人中心不重复放设置，版本号直接打开「系统与关于」。
- Windows 控制区避让：依次打开渠道编辑、提示词来源编辑、工作台底部抽屉、普通弹窗、大图预览及右上角完成通知，所有 Portal 浮层都应从 38px 主题顶栏下方开始；在支持的最小窗口尺寸下，最小化、最大化和关闭按钮不得遮挡取消、保存、关闭或通知操作。
- 首页侧栏与核心入口：左侧约 48px 整高区域都能唤出侧栏，小号品牌展示字体“工具栏”和朱砂描金笔触只负责提示，不是唯一命中目标。侧栏以约 380ms 从左侧阻尼展开，鼠标轻微离开后保留约 420ms 余量，返回时取消收回；从普通页面返回首页可沿用暂时停靠，从沉浸画布返回首页则应立即隐藏画布左栏与右侧对话，不保留 224px 槽位。导航悬停柔光带轻微黏滞、严格裁切在本项，点击从当前位置扩散一次并沉淀为静止暖金锚点，不得再有金色块上下移动；对话入口使用同一规则。Windows 38px 标题栏下底部操作完整可见，首页三个核心入口保持原样。

- 任务完成通知与精确跳转：在生图任务运行期间切到视频等其他页面，完成后应出现暖纸色通知卡和「查看结果」；点击通知主体或动作应返回来源工作台并直接打开对应记录。应用失焦时仍使用 Windows 系统通知并保持同样跳转；已停留在来源工作台时只显示简短成功反馈。
- 生成记录搜索与浮影：生图和视频生成记录应可按标题、提示词、模型、时间及尺寸/质量/分辨率搜索，输入时列表保持流畅，计数显示匹配数/总数，全选只处理当前匹配结果；无历史与无匹配应使用不同提示。浅色模式使用清晰的低透明度朱砂指针柔光但不得整卡染红，深色模式保持同等可读性。
- 参考素材排布：生图参考图、视频工作台参考图/参考视频/参考音频在数量增加时应向下铺开，不出现横向滚动；图片保持足够大的两列预览，视频和音频使用整行空间，序号、前移、后移和删除均不挤压。所有删除按钮在浅色、深色及复杂缩略图上都应清晰可辨。
- Windows 主题顶栏：浅色模式顶部窗口栏应融入暖纸背景，深色模式切换为暖墨背景，原生窗口控制覆盖层保持透明，缩小、最大化和关闭三个符号所在区域不得出现独立矩形色块；顶部空白区域仍可拖动窗口，符号对比清楚并随主题同步。
- 首页、设置与路由动效：依次切换首页、画布、生图、视频、素材、提示词、统计、设置及具体画布，支持 View Transition 的主路径使用统一 440ms 旧页退场与新页阻尼显现，并按导航相对顺序决定上下方向；后备环境使用同方向的 420ms 新页入场。两者都不得闪屏、生硬重叠或在结束后给文字残留 transform/模糊。设置长短分区切换不应横向抖动；重复当前路由、仅变更查询参数/哈希或设置内同一分区不得重播整页动画。
