# 四季画布设计系统

本文档是前端重设计的唯一权威说明，供后续开发与接入的 Agent 使用。改设计前先看本文档；本文档与实际代码冲突时以代码为准并回写本文档。

## 品牌

- **中文名：四季画布**；**英文名：FourJ Canvas**，简称 **FourJ**（2026-08-17 定名）。
- 含义：四个 J = 作者昵称 JJJJ；FourJ 谐音 For J（为你而造，呼应个人定制）；四季包含冬（作者喜欢 winter）。
- 品牌语：**四季流转，画布常新**。
- 标志：「游痕」——以连续、非对称的单一笔势形成四拍转折；不直画四个 J，而把 FourJ 的故事隐含在一次游走的笔迹中，见 `web/public/logo.svg`。
- 彩蛋空间：后续可在主主题上叠加春夏秋冬四季皮肤。
- 将来若公开分发，需先自查商标（第 9/42 类）与域名。

## 设计令牌

唯一色值源：`web/src/lib/design-tokens.ts`（TS 侧），三个消费方：

| 消费方 | 用途 | 同步方式 |
|---|---|---|
| `lib/app-theme.ts` | antd ConfigProvider token | 代码派生 |
| `lib/canvas-theme.ts` | 画布主题（canvasThemes） | 代码派生 |
| `styles/globals.css` | shadcn/Tailwind CSS 变量（`:root` / `.dark`） | **手动同步，改色两边一起改** |

antd 弹层、菜单、表格等组件级覆盖统一收在 `app-theme.ts`，业务组件不要单独覆盖弹层颜色，也不要在组件里写 `dark ? ...` 主题分支。

## 字体

| 角色 | 字体 | 引入方式 |
|---|---|---|
| 正文、导航、按钮、表单、状态与数字 | **MiSans**（可选系统安装）或原有系统无衬线回退 | 使用现有字体栈；公开快照不附带或联网加载 MiSans |
| 中文展示标题 | **Noto Serif SC Variable**（400 / 500） | `globals.css` 从 `public/fonts/mimo/` 本地加载 |
| 英文展示标题 | **PT Serif**（400） | `globals.css` 从 `public/fonts/mimo/` 本地加载 |

- 字体体系沿用 MiMo 排版组合；公开快照只随包分发 Noto Serif SC 与 PT Serif，并保留各自 OFL 许可，不依赖在线字体服务。MiSans 因再分发授权尚未确认而移除二进制；已安装时可由系统使用，否则使用既有系统回退。项目旧有的霞鹜文楷与 JetBrains Mono 不再加载或分发。
- 根页面统一使用 `text-rendering: optimizeLegibility` 与平台字体平滑属性。承载导航等小字号文字的容器在动效结束后不得保留 `transform`、`translate` 或填充动画，避免 Chromium 合成层重采样降低锐利度。
- Tailwind 字重令牌保持不变：`font-light` / `font-normal` / `font-medium` → 400，`font-semibold` → 500，`font-bold` / `font-extrabold` → 600；需要更强品牌强调时才明确使用 700。实际字形由安装字体或系统回退提供，须在目标 Windows 环境验证。普通标签和控件不得默认加粗。
- 中文与英文展示字体只用于页面标题、分区标题和首页品牌字；正文、导航、表单、按钮、列表、状态、数字与代码统一使用正文无衬线字体栈，避免一个界面无规则混用字体。下表的 MiSans 表示该字体栈的首选项，不承诺随包提供。
- 中文正文、标题、标签与控件使用字体原生字距（`0`/`normal`）；仅英文大写品牌元信息可使用不超过 `0.08em` 的克制字距。

| 语义类 | 规格 | 用途 |
|---|---|---|
| `.type-body` | MiSans 16 / 400 / 1.65 | 正文、说明 |
| `.type-label` | MiSans 13 / 400 / 1.5 | 标签、辅助操作 |
| `.type-section-title` | Noto Serif SC 20 / 500 / 1.4；英文 PT Serif 400 | 分区标题 |
| `.type-page-title` | Noto Serif SC 32 / 500 / 1.25；英文 PT Serif 400 | 路由页面主标题 |
| `.type-numeric` | MiSans 400 | 计数、时间、尺寸、代码 |
| `.type-display` | Noto Serif SC 400；英文 PT Serif 400 | 首页品牌展示标题 |

- Ant Design 的正文、按钮、级联与选择项从同一组 `typography` 令牌派生；正文和普通控件使用 400，选中项使用 500，明确的强强调使用 600。
- 1080P 的正文基准为 16px，常用辅助文字不低于 13px；2K/4K 由 CSS 像素和系统缩放保持一致的可读层级，不按物理分辨率盲目缩小界面。

### 文本选择边界

- 应用框架、导航、设置项、按钮、标签、卡片标题和普通说明默认不可拖选，避免桌面软件操作时出现无意义的文字选区。
- 输入框、文本域、富文本编辑区、代码与预格式化内容默认可选；词库详情、文本素材内容与备注、对话消息、工作区路径、错误详情等需要复制的正文必须显式使用 `data-selectable-text` 或 `.select-text` 放行。
- 不得用覆盖层拦截指针来实现禁选；交互控件继续保留正常点击、键盘焦点和辅助技术语义。

## 画布与对话交互

### 单一对话入口与上下文

- 画布只提供一个面向用户的「对话」入口，直接打开应用内置对话；画布内不出现 Agent 命名、内置/外部模式切换、Codex/MCP 连接状态、Skill 管理或额外安装入口。创作 Skill 的创建、导入、版本和启停统一放在资产区独立页面，画布对话只提供已启用可用 Skill 的紧凑选择，不增加用户完成画布任务前必须理解或配置的概念。
- 当前选中节点自动成为对话上下文，并在输入区上方以紧凑的上下文条显示；用户不需要再次通过文件选择或特殊语法引用已选内容。选中图片必须以真实多模态内容发送，最多取四张，不能只传节点名称、缩略图地址或内部 ID。
- 对话应能结合选中内容理解简短指令，先补足主体、动作、保留项和输出要求，再路由到编辑、扩图、超分、三视图或整理能力。「只润色提示词」只返回文字。输入区提供手动确认与自动确认两种模式，首次默认手动，只有用户明确切换后才自动执行；同时允许选择已配置的文字模型，并显示模型与渠道。手动确认卡默认展开并完整展示 AI 理解、参考图与目标、准备执行的动作、完整提示词、画幅、输出数量和模型调用次数，历史工具卡保持紧凑。每次确认最多执行一个生成类动作。提案绑定发出时的画布内容与选区，期间发生变化后旧卡自动失效；目标已有生成任务时拒绝重复启动。图片变换结果作为关联子节点加入且不覆盖原节点；失败或取消时不得用旧画布快照回滚并覆盖用户随后所做的编辑。

### 导航与视图

- 普通滚轮用于二维平移，`Ctrl/Cmd + 滚轮` 围绕指针位置缩放；高频视图更新使用 `requestAnimationFrame` 合帧，避免滚动时持续触发昂贵重排。可滚动的文本或编辑区域优先消费自己的滚轮事件，不得误带动画布。
- 底部工具栏显式提供选择与抓手两种模式；按住空格临时进入抓手，松开后恢复原模式，输入框和可编辑内容内仍能正常输入空格。中键平移、追加选择等既有直接操作继续可用。
- 适应视图完整容纳全部内容，适应选区只聚焦当前选择，100% 在保持当前视图中心的前提下恢复原始比例。所有固定格式控件都使用稳定尺寸，状态、图标或文字变化不得推动工具栏跳动。
- 一键整理优先处理当前多选内容，没有多选时处理全画布；按连线关系从左到右组织节点，分组作为整体移动并保持组内相对位置。整理不得改变节点内容、尺寸、分组归属或连线关系。

### 屏幕空间操作层

- 图片、文本等节点内容属于画布坐标并随视图缩放，以保留空间关系；节点标题、连接点、缩放命中区、选中操作和提示词输入属于屏幕空间操作层，应通过反向缩放或独立覆盖层保持稳定、可读、可点击的屏幕尺寸。
- 节点提示词输入在缩放或平移时跟随目标节点定位，但不随节点一起放大缩小；覆盖层应按实际占用矩形与节点工具条互相避让，并依据视口边界调整位置，避开顶部 64px 操作区、底部 Dock 和窗口安全区。上下空间都不足时仍须保留可编辑高度并在内部滚动，必要时允许覆盖节点本体，但不得压缩到不可用或与工具条重叠；小地图打开时缩放 Dock 移至另一侧避免遮挡。
- 浮动工具栏以真实操作内容收口，优先使用图标和悬浮提示；窄窗口先切换紧凑图标态，再在必要时限域滚动。缩放、悬停、选中、生成状态或长文案不得改变节点布局、推动其他控件或造成工具栏重叠。

### 极简工具栏与图片快捷动作

- 顶部栏只保留主页、所有画布、侧栏、画布标题和对话，使用无边框、无阴影、无胶囊底的低视觉重量样式。窄窗优先隐藏分隔线、文字和标题，但四个导航/面板图标始终可操作；插件管理、配置和其他低频入口统一收进「更多」或对应全局页面，不在顶栏重复展示。
- 底部主工具栏默认突出选择、抓手、添加、撤销/重做、整理、适应视图与更多；模式使用稳定选中态表达，朱砂只用于节点选中描边和品牌点缀，不用作大面积按钮填充。
- 图片节点的常用快捷动作固定为编辑、扩图、超分、三视图与更多，默认只显示熟悉图标并提供悬浮名称；扩图支持目标比例与可选说明，超分明确为高质量确定性放大而不虚称 AI，三视图分别产生正面、侧面与背面子节点。低频、危险或破坏性操作继续留在「更多」并按风险提供确认。

## 动效

- 产品动效符号定为「四季流韵」：**优雅、轻微黏滞但不拖沓**。朱砂表示悬停探索，香槟金表示点击确认；标准动作顺序固定为“朱砂跟随 → 原位扩散 → 鎏金确认 → 安静收束”，同一视野只保留一个主要动态焦点，禁止为不同页面重复发明扫光、弹跳或机械匀速动画。
- `design-tokens.ts` 统一提供 120 / 200 / 240 / 280 / 320 / 380 / 440ms 时长与 `out` / `settle` / `exit` 曲线。常规反馈使用 CSS，高频指针反馈使用 `requestAnimationFrame` + ref + CSS 变量，不因指针移动触发 React 重渲染。路由外壳固定为 `home / standard / immersive` 三类：`route-stage` 始终保持完整稳定矩形，224px 侧栏只作为内部布局槽位；使用 View Transition 的页面内跳转及自动 POP 为侧栏与移动顶栏提供独立且位于路由快照之上的分组，React Router 自动前进/后退在 `popstate` 内同步预备方向快照组，使旧、新快照按实际路径关系严格反向。真实 pathname 导航按单次事务绑定方向和驱动，区分待提交与活动事务，View Transition 与 Web Animations API 回退只能二选一；桌面侧栏点击固定使用 400ms 方向回退，让朱砂到暖金的 live DOM 确认不被顶层快照冻结或遮挡。主题揭示与路由事务共享互斥所有权，自动 POP 在 React Router 启动快照前必须同步终止并清理活动主题揭示，交叉操作必须跳过或延后其中一段，不得动态争用 root 快照。重复 pathname、query/hash 变化和修改键点击不创建整页事务。页面按导航顺序使用不超过 440ms 的可逆纵向小位移，向下级页面前进时新页从下方进入，返回时严格反向，位移限制在 10–14px，结束或中断后清理 transform、animation、快照和事务状态。
- 工具类（`globals.css`）：`.animate-fade-in-up`、`.animate-pop-in`；keyframes：`fade-in-up`、`pop-in`、`shimmer`。
- 主题切换：`body` 背景/文字 250ms 过渡。
- 首页首屏品牌字纹层固定只使用 `FOURJ` 铺满首屏并保持 `pointer-events: none`。阴刻底纹、闲置点染与指针阳刻显影复用完全相同的九行稳定单字符网格、字号、字距和坐标，不得单独缩放、平移或改变 inset。闲置时随机、分散地保持约 4–7 个字符轻柔点亮，每个字符只改变填色或透明度并完成约 2.5–4 秒的慢亮、短停、慢灭周期，同一字符设冷却且相邻字符不得连成扫动路径；主色为低强度朱砂，仅偶尔出现一个克制金色亮部。指针显影由较快的淡金光心与更慢、更大的朱砂光体分别维护位置、速度和转向记忆，速度驱动轻微拉伸，急转保留短暂回拉，停下后回圆收束。指针开始移动时闲置字符在约 400ms 内让位，停止约 1.3 秒后指针光先退出再恢复点染，两态不得长期叠加。禁止小圆点、细丝长尾、霓虹、扩散式闲置光斑和单条扫光。
- 首页桌面侧栏使用显式状态模型区分普通路由固定停靠、首页隐藏、首页覆盖层打开、内部交互持有、等待收回和正在收回。从沉浸画布返回首页时立即进入隐藏态，不保留画布左栏或 224px 槽位；从其他普通页面返回首页可沿用暂时停靠与容错收回。主题切换、版本号打开设置等侧栏内部动作从开始到过渡或弹窗完全结束都持有原停靠方式，重叠动作必须全部释放后才恢复悬停收回逻辑。完全隐藏后由左侧约 48px 的整高热区唤出覆盖层，不重复重排首页；小号“工具栏”文字和朱砂描金笔触只作为提示，侧栏可见时必须完全隐藏。隐藏或收回中的侧栏使用 `inert`、`aria-hidden` 与焦点回退保持视觉和辅助技术状态一致；Esc 关闭期间暂时抑制静止指针触发的热区重开，关闭后仍可再次用指针或键盘唤出。
- 导航悬停只在当前圆角范围内显示带轻微黏滞的朱砂柔光；点击从当前指针位置扩散一次并沉淀为静止的暖金选中锚点，不再让金色选中框跨项目上下游走。「对话」入口使用同一规则，悬停、选中和焦点互不残留。
- 对话面板以 380ms 与侧栏同层级开合，关闭或收回期间立即使用 `inert`、`aria-hidden` 并把焦点送回可见触发器或路由入口；快速关闭后重开必须取消旧计时器。面板宽度按当前视口、应用侧栏与画布左栏的实际槽位夹取，至少为任务区保留可操作空间，持久化值也必须使用同一夹取结果；桌面双侧面板把画布压到 240px 以下时自动收起画布左栏，移动端全屏对话不触发该规则。
- Windows 38px 原生窗口控制覆盖层使用透明底色，让网页标题栏成为贯通的唯一背景表面；窗口创建前按系统主题初始化原生符号与底色，正常首显等待 `ready-to-show` 和渲染进程主题同步，并设置有界兜底避免渲染或 IPC 异常导致窗口永久隐藏。浅色/深色切换只同步控制符号和窗口底色，不得在最小化、最大化、关闭区域形成独立矩形色块。页面正文、首页浮层、Ant Design 门户浮层和通知继续统一避让安全区。
- 首页第二屏进入视区时轻柔上浮；重复当前导航、仅切换查询参数、哈希或设置内分区时不重播整页动画。我的画布保持现有克制指针柔光；生图和视频生成记录统一使用小范围、无细丝的双层朱砂柔光，点击时只播放一次原位鎏金扩散，当前查看状态沉淀为静止的左侧暖金锚点，悬停光移出后必须消失，不能与勾选或焦点状态混合。
- 生图、视频等后台任务在用户停留于其他页面时完成，应显示可点击的暖纸色完成通知与「查看结果」动作；点击通知主体或动作后返回来源工作台并精确打开对应生成记录。用户已在来源工作台时只显示简短成功反馈，应用失焦时继续使用可点击的系统通知。
- 生图与视频生成记录提供本地搜索，覆盖标题、提示词、模型、生成时间和输出规格；筛选计数与全选只作用于当前可见结果，无匹配和无历史使用不同空状态。浅色与深色记录卡都使用低透明度朱砂指针柔光与细边，文字保持主题墨色并避免整卡染红。
- 生图与视频生成记录采用「正常 → 回收站 → 墓碑」生命周期。工作台删除只写入回收站状态并保留完整记录与成果文件；回收站支持恢复、筛选、批量操作和带安全确认的永久删除。永久删除先确认所有项目、素材、其他生成记录、当前工作台与临时未落盘记录的引用，再写入同步可传播的墓碑；只清理独占成果，参考输入与共享文件必须保留，损坏记录或保护扫描失败时拒绝物理删除。删除结果必须分别显示记录数、实际删除文件数、因引用保留数和失败数，并允许在删除前查看引用来源与存储标识；被引用文件不提供强制删除捷径。WebDAV 同步、生成日志写入和回收站操作使用同一串行边界，旧远端快照不得覆盖墓碑或复活已删除记录。
- 「创作统计」同时覆盖生图工作台与画布内的生成、改图、扩图、超分和三视图，并展示文本节点/字符数、活跃天数、连续创作、常用模型与时段、画布产出排行。文本来源分为纯手写、AI 生成、人机共创、导入和未知；旧数据不得猜测来源，未知与导入不进入手写/AI 占比分母。新增活动只保存版本化的时间、来源、动作、数量和归属等元数据，不保存提示词或正文，页面明确标记精细追踪启用时间，同时保留升级前已有的工作台生图统计。
- 创作统计明确拆成「历史创作」与「当前内容」：历史为独立追加记录，删除作品、画布、节点、素材、工作台记录、清空回收站或清理未引用媒体均不得减少；日期筛选只作用于历史。当前内容展示仍存在的节点与字符数，随删除实时变化且不受历史日期筛选影响。创作历史只能在「存储与空间」通过独立的危险操作和输入确认短语清除，不得并入回收站、缓存或媒体清理。
- 画布节点浮动工具条按当前真实操作内容宽度收口，不使用占满可用区域的空白外壳；当完整内容超过画布实际宽度时切换紧凑图标态，并在保留可见区安全距离的前提下允许横向滚动。
- 生图与视频工作台的实时结果、计时和活动记录必须通过记录 ID 绑定。查看历史只读预览，不覆盖正在运行的 prompt、参考素材或结果；运行记录允许点击恢复实时视图，但禁止勾选删除。APIMart 生图达到客户端轮询上限后保存为「状态待确认」并保留任务 ID，可继续查询同一任务，不得直接记为失败或重新提交。
- 桌面端拖入参考媒体时按内容复用已存在的工作区文件，包括用户自定义分类目录里的旧文件；同内容重复拖入不得复制落盘或重复追加引用。旧 `workspace:` 路径保持可读，不得为去重迁移、删除或覆盖已有资产。
- 生图与视频参考素材不使用横向滚动条；图片按两列向下铺开，参考视频和音频使用整行预览，序号、排序和删除操作保留足够点击面积。删除按钮使用主题自适应的浅底朱砂语义色，不得在深色缩略图上显示为难辨认的黑块。
- `prefers-reduced-motion: reduce` 时全局关闭动画与过渡，首页指针和路由过渡也必须主动停用。

## 桌面窗口

- Windows 使用 38px 原生窗口控制覆盖层，Electron 渲染层提供同高的可拖动区域；覆盖层背景、窗口底色和控制符号随浅色暖纸 / 深色暖墨主题同步，不自绘缩小、最大化和关闭按钮。macOS 保持各自的桌面窗口行为。

## 设置页信息架构

- 创作统计、回收站、设置、画布列表、我的素材和提示词库等标准路由页共用同一页头：只保留页面标题、说明与右侧操作区，不显示 eyebrow、表情或装饰性图标；标题下方使用统一分隔线与间距。工作台和沉浸画布继续使用各自的任务界面，不套标准页头。标准系统页不使用页面独有的顶部渐变。
- 设置页固定为六个同级分区：AI 服务、创作偏好、同步与迁移、存储与空间、内容来源、系统与关于。桌面使用左侧二级导航，窄屏自动回到顶部导航。
- 配置导入导出与 WebDAV 归入「同步与迁移」，并明确导出文件包含 API Key/WebDAV 凭据、WebDAV 不是版本备份；本地工作区、占用与健康检查、未引用媒体安全清理、缓存和回收站入口归入「存储与空间」。关闭行为、更新、版本、文档和开源说明统一归入「系统与关于」。生成记录不再从存储清理中直接整库删除，必须进入回收站完成恢复或永久删除。
- 普通打开设置时恢复上次访问分区；未完成 AI 服务或由缺少模型触发设置时必须直接进入「AI 服务」。创作偏好明确显示自动保存反馈，渠道删除必须二次确认。
- 左侧系统区是唯一常规设置入口；个人中心不重复放设置，版本号只定向打开「系统与关于」，缺模型等提示只进入对应分区。编号章节的序号保持 12–13px，章节标题使用 19–20px 展示层级，说明 14px、正文 15–16px。
- 设置页滚动容器始终预留对称滚动条空间，长短分区切换不得引起横向位移；桌面页头与左侧分区导航固定，仅右侧内容独立滚动，完整设置页与设置弹窗遵循同一规则。长分区使用带序号的编辑式章节、行式内容和明确留白建立层级，只为独立功能、状态或危险操作保留卡片容器，避免连续同规格卡片造成拥挤和审美疲劳。
- 设置分区内的可见章节必须由同一章节数组渲染，并按数组顺序自动生成 `01/02/03` 序号；条件隐藏章节后立即重排，禁止在 JSX 中硬编码序号。章节标题不附加装饰性图标，按钮、导航、状态、指标和列表行仍可保留功能图标。

## 决策记录

- 最终标志采用「游痕」：用一次连续、非对称的笔势完成四拍转折，以隐含而非直画的方式保留 FourJ 故事。

- 项目实为 antd + shadcn/radix 混用，`globals.css` 的 shadcn 变量体系是 Tailwind 侧主题入口，改色值不改变量名。
