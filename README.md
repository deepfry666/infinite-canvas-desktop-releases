# 四季画布 FourJ Canvas

四季画布是一款本地优先的 AI 视觉创作桌面应用，把无限画布、图片与视频生成、素材管理、提示词、创作记录和内置对话集中在一个工作区中。

应用直接安装到 Windows 使用，不需要 Docker、Node、Codex 或单独部署服务。用户自行配置 AI 服务，画布、素材和生成记录保存在本机工作区，也可在设置中调整各类内容的目录。

> 当前功能说明按最新正式版 `v0.1.10` 整理。测试版通道当前为 `v0.1.11-beta.4`。

## 快速开始

1. 准备一个兼容的 AI 服务 Base URL、API Key 和可用模型；模型调用费用由对应服务商收取。
2. 下载对应更新通道的 Windows x64 安装包并完成安装。
3. 打开“设置 → AI 服务”，添加渠道，并测试连接或读取模型。
4. 在“创作偏好”中选择默认图片、视频、文字和音频模型，设置常用生成参数。
5. 在“存储与空间”中确认总工作区及各类文件的保存目录，并为重要内容保留独立备份。
6. 从“我的画布”“生图工作台”或“视频创作台”开始创作。

## 软件功能

### 画布项目与节点编排

- 创建和管理多个画布项目，支持重命名、批量选择、删除，以及包含项目数据和本地媒体的 ZIP 导入和导出。
- 在无限画布中平移、缩放、框选、多选、复制粘贴、连接节点，并使用小地图快速定位。
- 使用文本、图片、视频、音频、生成配置和分组节点组织创作流程。
- 通过连线组合上下游素材；提示词输入支持 `@` 引用已连接的图片、文本、视频和音频。
- 支持撤销、重做、快捷键、三种画布背景和深浅主题；还可一键适应全部内容、聚焦选区、恢复 100% 缩放或自动整理节点。
- 图片批量生成结果以图片组集中展示，可展开查看、切换主图、单独重试失败项。

### 图片创作

- 在生图工作台完成文生图和参考图生成，可设置模型、质量、分辨率、比例、透明背景和生成数量。
- 从剪贴板、本地文件或“我的资产”添加参考图，并按内容复用已有工作区文件，避免重复保存。
- 生成任务与记录独立计时；切换页面或查看历史记录不会覆盖正在运行的任务。
- 在画布中对图片进行替换、裁剪、蒙版编辑和切图；还提供扩图、超分、三视图和多角度生成，结果作为关联节点保留。
- 支持下载结果、保存到“我的资产”，以及失败后重试或继续查询长耗时任务。

### 视频与音频

- 在视频创作台使用提示词、参考图片、参考视频和参考音频生成视频，并按模型能力设置比例、分辨率、时长、声音和水印。
- 画布视频工作流可组合文本、图片、参考视频和参考音频，生成结果直接写回视频节点并在节点内播放。
- 音频节点支持上传、播放，并可使用已配置的音频模型生成内容。
- 支持 OpenAI 兼容视频接口、火山方舟 Seedance，以及 APIMart 的 Seedance、MiniMax 等异步任务流程；实际参数范围以所选模型和渠道为准。

### 画布内置对话

- 每个画布提供一个内置“对话”入口，无需安装 Codex、MCP、Canvas Agent 或其他本地服务。
- 对话可以读取当前选中内容，回答问题，把简短描述扩写为完整提示词，并提出改图、扩图、超分、三视图或整理画布等操作。
- 支持手动确认和自动确认。手动确认会先展示 AI 的理解、参考素材、目标、完整提示词、画幅、数量和预期动作。
- 可选择已配置的文字模型，并创建、切换、重命名和删除多个本地对话；经确认执行的部分同步画布修改可通过撤销恢复。

### 节点插件

- 可从官方注册表或可信 URL 安装节点插件，并进行启用、停用、更新和卸载。
- 提供 Markdown、SVG、HTML、3D 全景和便利贴等扩展节点，也可使用 TypeScript SDK 开发自己的节点类型。
- 节点插件会在应用渲染进程中执行代码，可能读取本地数据和 API Key，并通过网络发送这些信息；仅安装可信且经过审阅的插件。

### 我的资产与提示词

- “我的资产”可保存文本、图片和视频，支持搜索、筛选、编辑、预览、复制、下载和插入画布。
- 支持虚拟文件夹、未归档筛选、批量移动，以及带媒体文件的素材包导入和导出。
- 提示词中心支持搜索、查看详情与参考图、复制提示词，并把内容加入“我的资产”。
- 内置多个提示词来源，也可添加自己的远程 JSON 来源；各来源可以独立启用、更新并保留本地缓存。

### 生成记录、回收站与统计

- 生图和视频工作台保存生成记录，可按标题、提示词、模型、时间和规格搜索。
- 任务在其他页面完成时会显示通知，点击可回到对应记录；运行中的记录可以随时点回实时视图。
- 删除的生成记录先进入回收站，可恢复、批量永久删除或清空。
- 永久删除和未引用媒体清理会先检查画布、资产、生成记录和当前工作台引用，仍在使用的文件会被保留。
- 创作统计区分“历史创作”和“当前内容”，覆盖图片、视频、音频、文字与提示词润色，并展示成功率、取消数量、活跃时段、文本来源和画布产出排行。

### AI 服务与中转渠道

- 支持配置多个 AI 渠道，为图片、视频、文字和音频分别指定默认模型。
- 支持 OpenAI 兼容格式；图片与文字支持 Gemini，视频支持火山方舟 Seedance；另内置 APIMart GPT-Image-2 及常用视频模型适配。
- 渠道可使用协议预设或声明式字段映射，特殊模型还可单独覆盖调用方式。
- 对已内置能力规则的模型，应用会提前限制不支持的比例、数量、时长和参考素材组合，减少提交后才发现参数无效的情况。
- Base URL、API Key、模型和生成偏好均由用户自行配置，模型费用由对应服务商收取。

### 本地存储、同步与桌面体验

- 画布、素材、生成记录、图片、视频和音频保存在本机工作区，可为不同内容分别指定目录。
- 切换到空的新目录时会复制现有文件，切换到已有四季画布数据的目录时会直接打开其中内容；操作前会创建恢复点。存储页可查看占用、执行健康检查和清理未引用媒体。
- 可导入、导出应用设置，并通过可选 WebDAV 在多台设备间同步画布、资产、生成记录、创作历史和本地媒体。
- Windows 关闭按钮默认把应用隐藏到系统托盘，让生成任务继续运行；也可改为关闭时完全退出。
- 支持稳定版和测试版两个应用内更新通道，下载、安装和升级完成前后均有明确提示。
- 提供中文与英文界面、浅色与深色主题，并遵循系统的“减少动态效果”设置。

## 数据与隐私

- 应用不要求登录账号，也不提供项目方运营的云端工作区。
- API Key 保存在桌面应用的本地配置中，生成请求由应用直接发送到用户配置的 AI 接口，不经过项目方服务器。
- 设置导出文件会包含已配置的 API Key 和 WebDAV 凭据，只应保存在可信位置，不要公开分享。
- WebDAV 是用户自行配置的跨设备同步方式，不是带历史版本的云备份，也不能替代独立备份。
- 本仓库只提供安装包、自动更新文件和版本说明，不包含应用源码、开发历史、用户配置或生成内容。

## 使用前须知

- 当前仅公开 Windows x64 安装包，不提供网页端、Docker、Vercel、Render 或云账号版本。
- AI 生成功能需要可用的网络和兼容接口；不同服务商对模型、参考素材、文件大小和参数的支持可能不同。
- 部分视频接口返回的远程地址可能有有效期。应用会尽量保存到本地，但网络或上游下载限制可能影响保存。
- 在更新版本、切换工作区或清理文件前，建议先独立备份重要项目和媒体。
