# Font resources

Noto Serif SC and PT Serif are bundled with their unmodified original font files, copyright notices and SIL OFL texts. See the root `THIRD_PARTY_NOTICES.md` for provenance.

MiSans binaries are not distributed in this public source snapshot. The existing font-family stack uses MiSans only when it is already installed on the user's system, otherwise falling back to the existing system fonts. This avoids requesting missing WOFF2 files. Review MiSans terms and obtain an authorized original directly from https://hyperos.mi.com/font/download if desired; do not commit local copies here.
